# AITC Lite

按模块逐步实现的 AI 测试工作台。前端 Vue 3 + TypeScript + Element Plus，后端 FastAPI + SQLAlchemy + SQLite。

**当前实现模块 01–23：项目、需求、生成配置、LangGraph 工作流与评审导出、可恢复任务、知识分块、BM25、独立 Embedding 配置、Chroma 向量语义检索、RRF 混合检索、可选 Rerank 精排、RAG 引用追溯、专项 Skill、AI Judge、项目 Agent 助手、MCP 客户端、人工执行管理、离线评测及项目工作台。** 当前 0.23.0 完成实际进度、配置摘要和下一步指引；真实需求原文待用户提供。

[集成验收与学习路线](docs/集成验收与学习路线.md) 提供一条不改真实配置的自动烟测和三轮手工验收步骤。

## 启动

需要 Python 3.11+、Node.js 22.12+（也可用 Node 24）。以下终端均从本目录 `aitc-lite/` 开始操作。

首次安装：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements-dev.txt
cd web
npm ci
```

终端一，启动后端：

```bash
source .venv/bin/activate
cd backend
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

终端二，启动前端：

```bash
cd web
npm run dev
```

访问前端 <http://127.0.0.1:5174>，接口文档 <http://127.0.0.1:8001/docs>。在终端按 Ctrl+C 停止对应服务。前端 `/api` 由 Vite 代理到后端，因此无需额外配置 CORS。

使用独立端口，不占原项目的 8000/5173。开发数据位于 `backend/data/aitc-lite.sqlite3`，不读取原项目 `.env` 或数据库。单人本地使用，开发服务只监听回环地址。

## 检查

后端，从 `aitc-lite/` 开始：

```bash
source .venv/bin/activate
cd backend
python -m unittest discover -s tests -v
```

前端，从 `aitc-lite/` 开始：

```bash
cd web
npm run build
```

后端测试使用临时数据库，不污染开发数据。`build` 包含 TypeScript/Vue 类型检查和生产构建。`npm run preview` 仅预览静态产物；本模块联调和验收使用 `npm run dev` 的 API 代理。

## 当前功能

- 项目列表，按最近更新时间排序。
- 新建、编辑项目名称和描述，前后端校验输入。
- 按名称或描述在当前项目列表中搜索。
- 删除二次确认；取消不会删除。
- SQLite 持久化，刷新或重启后数据保留。
- 加载、空列表、搜索无结果、请求错误与重试状态。
- 点击项目名称或“需求”进入项目需求页面，直接刷新地址仍停留在该项目。
- 在项目下创建、查看、编辑、搜索标题和删除文本需求，正文保留空格、缩进与换行。
- 未保存的需求修改在关闭编辑器、切换页面和刷新时有提醒；保存失败保留输入。
- 删除项目会级联删除所属需求，确认框明确提示这一影响。
- 模型设置：保存生成模型根地址、模型标识、Key、超时与显式 Mock 开关。
- 测试已保存的配置；区分 Mock 流程验证和真实对话连接，失败不会自动启用 Mock。
- Key 留空保留、输入新值替换、勾选清除；读取和错误响应不回显原 Key。
- 需求列表点击“功能点”，可调用已保存模型拆解需求；AI 结果先预览，保存后才入库。
- 功能点支持人工增删改、优先级和验收标准、选择纳入范围、保存与确认。
- 原文变化使有效确认失效；清单版本与内容哈希保护过期写入，冲突不覆盖数据。
- 每次选择一个已确认功能点，通过 LangGraph 生成完整或冒烟用例草稿，校验成功后自动保存。
- 查看历史草稿、生成依据快照与节点过程；成功请求的同 ID 重试不重复调用模型或保存。
- 原文和功能点变化不覆盖历史草稿，新生成需重新确认范围。
- 待评审草稿可人工编辑、采纳、填写原因驳回，AI 原稿保留；已完成结论锁定。
- 项目已采纳用例支持搜索与冒烟筛选，保留 Mock 来源、人工编辑和依据过期提示。
- 按当前筛选结果导出 Excel 或 Markdown，包含最终人工版本和追溯信息，每次最多 1000 条。
- 后台生成任务先入库后执行，查看排队、阶段进度、完成、失败和中断状态；可离开或刷新页面。
- 同一需求活动任务互斥；服务重启核对已保存结果，其他未完成任务标为中断，不自动重发模型调用。
- 节点边界暂停、检查点持久化及手动恢复；复用已保存模型结果，未知模型调用结果需要明确确认重试。
- 项目知识文档录入和 UTF-8 TXT/Markdown 导入，自动分块、原文位置预览及版本保护。
- 文档编辑原子替换旧分块，删除级联清理；BM25 检索按当前项目有效正文分块临时构建索引。
- 查看查询词项、排名与分数、命中来源和分块定位；用例生成页可开启 RAG 并查看注入与引用快照。
- 独立 Embedding 配置与固定双文本连接验证，支持显式 Mock、向量维度和格式检查。
- 项目知识全量分批向量化、后台进度与 Chroma 持久索引，支持语义检索、相似度和来源定位。文档或向量空间配置变化后需重建；失败不发布半成品，重启中断不自动重试。

- RRF 混合检索：等权合并 BM25 与向量候选，按分块去重，展示两路名次与贡献；单路失败明确降级，两路不可用返回错误。

- 独立 Rerank 配置与连接测试；混合检索可选精排，展示原始 RRF 名次、最终名次和精排分数，失败完整回退 RRF。

- 用例生成可选 RAG：项目混合检索与精排、最多 5 块知识注入、AI 原稿引用 ID 校验、历史来源快照、暂停恢复复用及无知识降级的明确选择。

- 可选接口测试与安全/权限 Skill，固定注册表、独立 Prompt 和 handler；保存版本、规则快照及 AI 原稿专项覆盖声明，复用一次生成调用。

- AI Judge 独立评估当前人工版本，默认复用生成模型或使用独立配置；三维评分、疑似幻觉、本地重复提示、输入快照与失败重试不改写草稿或人工结论。

- 项目 Agent 共用侧边栏：原生工具调用与 LangGraph 循环、六项项目只读查询、SSE 工具过程、会话持久化与项目隔离；Mock 不调用外部模型，失败与重启不自动重放。

- MCP 客户端：stdio / Streamable HTTP、服务配置与发现、项目工具启停和人工分类、原生 Agent 调用、写入/未知逐次确认、审计与副作用重复保护。

- 人工执行：从采纳用例创建固定快照，记录通过/失败/阻塞和实际结果，保留修改历史；任务结束锁定、来源删除不改历史、统计分母明确，Agent 可只读查询。

- 离线评测：独立样本和标准点、批量生成/Judge、词面召回证据、重复/疑似幻觉/Token/耗时指标、Mock 零外部请求、固定快照及共同样本运行对比。

不允许纯空白名称；项目名称最多 100 字、描述最多 2000 字。需求标题最多 200 字，正文最多 50000 字，两者均不能为空或纯空白。项目和需求允许重名，靠 ID 区分。删除不可恢复；需求之间及不同项目之间互不影响。

从模块 01 升级：在 `web/` 执行 `npm ci` 安装新增的 Vue Router，重启后端即可自动创建新增的需求表，已有项目保留。若服务以 `--reload` 运行，代码更新时会自动重启。

模块 03 将 HTTPX 加入后端运行依赖，按首次安装命令更新依赖并重启后端即可新增配置表。访问侧栏“模型设置”，或直接进入 <http://127.0.0.1:5174/settings>。第一次不默认启用 Mock，也不读取原项目的模型凭据。

模块 04 无新增依赖，重启后端会新增功能点清单和功能点表，已有项目、需求和模型设置保留。使用路径：项目 → 需求 → 功能点 → AI 拆解 → 保存 → 确认。真实模式会向用户配置的模型发送所选需求的标题和正文。

模块 05 新增 `langgraph==1.2.9`，需在独立 `.venv` 中重新执行 `python -m pip install -r backend/requirements-dev.txt`。后端重启时新建生成记录和草稿表，已有数据与模型配置保留。使用路径：需求 → 用例草稿 → 选择已确认功能点和策略 → 生成。模块 05 当时未配置检查点；模块 09 已实现节点检查点、暂停和恢复。

模块 06 无新依赖，后端重启时只新增 `case_reviews` 表。已有草稿自动按待评审展示，不改写 AI 原稿。评审操作不调用模型；项目列表和评审页均可进入“已采纳用例”。

模块 07 新增 `openpyxl==3.1.5`，按首次安装命令更新后端依赖并重启；无需迁移数据库。使用路径：项目 → 已采纳用例 → 搜索/仅冒烟（可选）→ 导出 Excel 或 Markdown。导出不调用模型。

模块 08 无新增依赖，重启后端自动创建任务表，已有结果保留。仍按单进程启动命令运行，不要启用多个 worker。模块 08 当时仅持久化任务进度；模块 09 已增加检查点、暂停和恢复。

模块 09 显式锁定 `langgraph-checkpoint==4.3.0`，更新后端依赖并重启即可创建检查点和控制表。使用路径：用例草稿 → 生成任务 → 暂停 → 等待已暂停 → 恢复任务。旧版没有控制记录的任务不可补造节点检查点，历史成功草稿仍保留。

模块 10 无新增依赖，重启后端创建知识文档与分块表。使用路径：项目 → 知识库 → 新建知识文档 → 粘贴或导入 TXT/Markdown → 保存并分块。此操作不调用模型，尚不影响用例生成上下文。

模块 11 新增 `jieba==0.42.1`、`rank-bm25==0.2.2` 和兼容 Python 3.11+ 的 `numpy==2.3.5`，更新依赖并重启后端。使用路径：项目 → 知识库 → BM25 关键词检索。无需新表或外部服务，不调用模型。

模块 12 无新增依赖，重启后端自动创建 Embedding 配置表；访问侧栏「Embedding 配置」。此配置不复用或修改生成设置。模块 12 当时只验证连接，模块 13 已接入向量化和语义检索。

模块 13 新增 `chromadb==1.5.5` 及兼容原 Pydantic 的依赖版本约束，更新后端依赖并重启。使用路径：项目 → 知识库 → 构建向量索引 → 语义检索。向量保存至 `backend/data/aitc-lite-chroma/`。构建会调用已保存的 Embedding 服务，暂不支持构建断点续传；用例生成的暂停/恢复继续可用。

模块 14 无新增依赖或表，重启后端并刷新前端即可使用「项目 → 知识库 → RRF 混合检索」。向量不可用时明确降级到当前 BM25；向量可用时每次查询调用一次 Embedding。

模块 15 无新增依赖，重启后端新增独立 Rerank 配置表。侧栏「Rerank 配置」保存并测试后，在混合检索勾选「启用 Rerank 精排」。真实精排额外发送查询和入选候选正文，可能计费；默认关闭。

模块 16 无新增依赖，启动后端创建知识快照表。使用路径：需求 → 用例草稿 → 勾选「使用项目知识 RAG」→ 生成 → 查看「知识注入与引用追溯」。默认无候选停止；主动允许无知识继续时记录降级原因。新流程版本与旧未完成检查点不兼容，旧任务需重新发起，历史成功草稿保留。

模块 17 无新增依赖，启动后端创建专项快照表。用例草稿页可单独或同时选择「接口测试」「安全与权限」，普通生成默认不选。版本变化阻止旧任务混用新规则；历史成功记录保留。专项覆盖声明尚不等于质量结论，模块 18 已增加独立 AI Judge。

模块 18 无新增依赖，启动后端新增 Judge 配置和评估记录表。默认复用生成模型；用例草稿下方点击「评估当前草稿」。每次评估单独调用模型，失败或中断不会自动重试；报告保留输入快照，人工编辑后旧评分标记过期。

模块 19 无新增依赖，重启后端新增项目会话、提问轮次和工具审计三张表。项目页右上角「项目助手」查询需求、知识、用例与 Judge，复用生成模型并使用原生 Tool Calls；调用过程与对话持久化，重启中断不自动重试。外部 MCP 为下一模块。

模块 20 新增官方 MCP SDK、兼容的 sse-starlette 和 JSON Schema 校验依赖，请更新依赖并重启后端，自动新增四张 MCP 表。侧栏「MCP 服务」配置并发现工具，再在项目助手中绑定和授权；写入/未知工具逐次确认，失败或重启不自动重放。自带本地演示服务，详见模块 20 文档。

模块 21 无新增依赖，重启后端创建人工执行任务、条目和结果事件三张表。项目列表「测试执行」或已采纳用例页进入，选择用例保存快照后手工记录，全部记录后结束并锁定；不调用模型、MCP 或脚本。

模块 22 无新增依赖，重启后端新增评测样本、运行和结果三张表。项目列表「离线评测」录入独立样本并批量运行，支持显式本次 Mock、生成/专项/RAG/Judge 复用及共同样本对比；结果不进入正式用例库，停止或重启不自动重放。真实运行仍需联网且可能计费。

模块 23 无新增依赖和表。点击项目名称进入只读工作台，汇总当前项目的实际数据与下一步入口，明确区分真实/Mock、已保存配置/已验证连接、记录数量/质量结论；不会自动调用模型或写入业务数据。
